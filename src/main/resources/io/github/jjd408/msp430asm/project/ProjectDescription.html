An MSP430 program made of several source files. Everything in the project's src folder (assembly .s .S .s43 .asm and C .c) is built with MSP430-GCC into one build/<name>.hex, which Run loads into PICSimLab.

The new project has a starter program in two files: main.S blinks P1.0 and calls delay in delay.S. Its device, C flags and PICSimLab board are in msp430-project.properties.
